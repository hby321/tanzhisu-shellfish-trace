🛠️ 技术栈详情
🖥️

后端框架

  • Python 3.x
  • Flask 3.0.0
  • Flask-SQLAlchemy 3.1.1
  • Flask-Login 0.6.3
  • Flask-CORS 4.0.0
  • Werkzeug 3.0.1
🤖

AI智能体

  • 独立 Flask 服务
  • DeepSeek 大模型
  • llm_chat() 封装
  • 9大智能体调度
  • 本地知识库降级
  • 软著 V1.0 知识产权
🌐

前端技术

  • HTML5 / CSS3
  • JavaScript (ES6+)
  • Jinja2 模板引擎
  • ECharts 数据可视化
  • Leaflet 地图
  • 高德地图瓦片
📱

移动端

  • Taro 4.1.9
  • React 18
  • TypeScript 5
  • Zustand 状态管理
  • Sass CSS
  • 多端适配
💾

数据存储

  • SQLite 数据库
  • SQLAlchemy ORM
  • Hash 区块链存证
  • 数据模型分离
  • 实时数据采集
  • 历史数据存档
🔌

外部接口

  • 高德地图 API
  • 和风天气 API
  • HTTP Client
  • JSON 数据格式
  • 超时重试机制
  • 错误降级处理
